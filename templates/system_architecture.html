Algorithmic Depth

Swiftpath isn't just a CRUD application; it operates a **Two-Tier Optimization Pipeline**:
1. Fleet Dispatch: Uses a Greedy heuristics approach based on Euclidean distances and battery limits.
2. Route Planning: Leverages Dijkstra's Single-Source Shortest Path over a modeled mesh grid to minimize delivery path costs and predict battery usage before dispatching.

Software Engineering Best Practices

- State Separation: Calculations are computed on the server side using SQLite/Postgres persistence, while UI rendering is completely decoupled. - Safe DB Migrations: Seed operations only occur if tables are completely empty, safeguarding staging and production assets. - Visualizations: Dynamic SVG projection algorithms avoid overlapping labels and nodes on the tracking dashboard.
